# :gift: Desiroo Frontend

Desiroo — это приложение для создания и управления виш-листами с социальными функциями. Данный репозиторий содержит код фронтенда.

## :rocket: Стек технологий

- React — библиотека для создания пользовательских интерфейсов

- TypeScript — строгая типизация для JavaScript

- Tailwind CSS — утилитарный фреймворк для стилизации

- Redux — управление состоянием

- React Query — работа с запросами к API

- React Hook Form — управление формами
